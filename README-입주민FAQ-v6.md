- FAQ 화면 주소는 `index.html#faq`입니다. 개별 항목은 `#faq/fees`, `#faq/elevator`, `#faq/painting`, `#faq/vote`, `#faq/term`입니다.
- 홈페이지 첫 화면에도 5개 질문 바로가기 카드를 넣었습니다.
- 기존 사진 갤러리, 승강기 비교 리포트 및 큰 글씨 기능을 보존했습니다.

## 추가된 파일

- `public/resident-faq.js`: FAQ 본문(문구·요율표·비용 근거)을 수정하는 곳.
- `public/resident-faq.css`: FAQ 디자인, 모바일 반응형 스타일.
- `public/assets/docs/장기수선충당금-요율-개정안.png`: 제공된 관리규약 요율표 원본 이미지(첫 번째 캡처).
- `public/assets/docs/외벽도색-시공방식-참고자료.pdf`: 제공된 도색 참고자료.
- `public/index.html`, `public/app.js`, `public/content.js`: 홈 바로가기·라우팅·관련 게시글 수정.

**참고:** 주민이 보내준 자료 중 나머지 캡처 3장은 독립 파일로 포함되지 않아, 화면에 식별 가능한 수치와 텍스트를 FAQ에 재구성했습니다. 공식 문서 이미지가 있다면 원본을 추가하는 것이 좋습니다.

## 공개 전에 반드시 확인할 내용

1. **실제 월 장기수선충당금 인하액**: 현행 15.00%(2025~2034)와 개정안 6.35%(2025~2027)는 적립 구간이 달라 단순 비교할 수 없습니다. `57.7% 인하` 같은 문구는 사용하지 않았습니다. 세대별 평형, 월 부과액, 적용시기가 포함된 시뮬레이션 표를 확보한 뒤 추가하세요.
2. **승강기 협상 절감액**: 회장님의 적극적인 협의 사실은 전달받은 설명에 따라 소개했으나, 객관적인 절감액(최초 견적 대비 최종 계약)이 확인되지 않아 숫자를 적지 않았습니다. 비교자료 19개 단지는 사양이 다르므로 동등 조건 비교가 필요합니다.
3. **도색 비용**: 제공된 수선계획 표상 기존 외벽도장(266,668천원) + 지붕방수(138,461천원) = 405,129천원, 변경(안) 580,000천원. 기존 계획 대비 증액 174,871천원. 이는 계획금액이지 공사 계약 확정가가 아닙니다.
4. **투표의 정확한 안건·요건**: 투표 공고문과 의결 요건에 맞게 문구를 업데이트하세요. 요율 개정이 부결되면 이번 개정안은 적용되지 않으나, 정확한 월 부담액의 인하는 별도 산정이 필요합니다.
5. **행정지도·과태료**: 성북구청에서 3회 지도를 받았다는 설명은 사용자 제공 내용으로 반영했으나 세 개의 공문 자체는 포함되지 않았습니다. 행정지도 자체의 불이행을 이유로 과태료가 자동 부과되는 것은 아닙니다. 공문·근거 법령·처분 요건을 확인하고 확정 문구를 게시하세요. 법령상 임기 2년, 원칙적 1회 중임, 예외적 선출 허용 기준은 유지됩니다.
