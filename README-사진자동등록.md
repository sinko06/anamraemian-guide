# 안암래미안 외벽 사진 자동 등록 — v5

## 제일 간단한 적용법
1. 압축파일 안 `public/content.js`를 기존 VS Code 프로젝트의 `public/content.js`와 교체합니다.
2. **내 PC에 이미 있는** `public/assets/photos/`의 사진들은 그대로 둡니다. (다운로드 ZIP에는 사진 원본이 포함되지 않습니다.)
3. VS Code에서 Live Server 등으로 `public/index.html`을 미리 봅니다.
4. 첫 화면에서 외벽 보수·도색 → 동별 외벽 현장 사진 및 보수·도색 안내를 열어 101동 10장, 102동 8장, 103동 5장 총 23장이 나타나는지 확인합니다.

## 나중에 112동까지 추가할 때
`public/content.js` 상단의 `exteriorPhotoCounts`에서 `104동: 0`처럼 설정된 숫자를 실제 사진 수로 바꿉니다.
예: 104동에 (1)~(25)까지 파일 25개를 넣었다면 `'104동': 25`로 변경합니다.

사진 이름은 `101동 (1).jpg`처럼 **띄어쓰기, 괄호, 확장자**가 정확히 맞아야 합니다.
예를 들어 `101동(1).jpg`, `101동 (1).JPG`는 호스팅에서 다른 파일로 처리됩니다.
번호가 1부터 연속되어 있어야 하며, 중간에 없는 번호가 있으면 해당 사진이 깨집니다.

## 사진별 설명 바꾸기
같은 파일에서 `exteriorPhotoCaptions`에 추가하면 됩니다:

    const exteriorPhotoCaptions = {
      '101동 (1).jpg': '101동 외벽 균열 확인 지점',
      '102동 (3).jpg': '102동 외벽 표면 보수 필요 부위'
    };

(실제 현장 확인을 거친 설명만 적으세요.)

## 중요: 로컬 사진의 자동 검색 여부
Cloudflare Pages 같은 정적 사이트에서 브라우저 JavaScript가 서버의 `/assets/photos/` 디렉터리를 자동으로 나열할 수는 없습니다.
따라서 사진 번호를 자동으로 반복 생성하는 것은 가능하지만, 동별 **마지막 사진 번호(개수)**는 직접 입력합니다.

이 버전은 홈페이지에 있는 기존 승강기 비교 게시물과 디자인을 변경하지 않았습니다.
Cloudflare 배포는 나중에 직접 하셔도 됩니다.
